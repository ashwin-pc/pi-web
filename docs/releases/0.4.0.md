# pi-web 0.4.0

0.4.0 refreshes the visual polish for the browser UI while keeping the compact pi workflow intact.

## Highlights

- Switches the default dark theme to a more neutral black/gray palette.
- Simplifies active session tabs with a dark gray background and legacy blue top border.
- Keeps marked active tabs aligned to their marker color and brightens inactive marked tabs for easier scanning.
- Adds a compact inactive composer state with model/reasoning and attach controls visible.
- Keeps stop available from the compact composer while a run is active.
- Uses the legacy blue context bar once context utilization passes 50%.
- Refreshes README-backed visual snapshots for the current UI.

## Validation

- `npm test`
- targeted visual snapshot refresh for desktop and mobile README screenshots
