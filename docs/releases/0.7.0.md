# pi-web 0.7.0

0.7.0 adds portable app identities, a searchable model picker, and a dedicated instance launcher, alongside session-state, preview, and startup reliability improvements.

## New capabilities

- Customize the app name and avatar, choose built-in identity presets, and import/export self-contained `.pi-avatar.zip` bundles. Custom identities support separate favicon/FAB artwork, static PNGs and animated APNGs, with bounded validation and generation, offline cache management, and consistent live manifest updates.
- Search and navigate models in a scannable picker, refresh provider catalogs on open, and retain session drafts when switching models.
- Launch and manage instances through pi-web home, including standalone extension support.
- Navigate session images and artifact previews in a shared viewer, with pan/zoom gestures, preview history, and keyboard navigation.
- Optionally pin new sessions automatically and reuse empty tabs.
- Smoothly reveal streamed assistant text while preserving grapheme continuations.
- Add an optional portable local image-tool example with configurable Qwen profiles and safer ComfyUI process/path handling.

## Fixes and reliability

- Protect session UI preferences against stale-tab overwrites using revisioned intents and validated recovery; keep chat usable when preferences are read-only and surface committed metadata warnings.
- Preserve transcripts and focus on failed or overlapping session opens, projected message action targets, worker expansion, and explicit streaming scroll intent.
- Render inline HTML artifacts, preserve session deep links, and show Mermaid rendering errors.
- Keep the composer and extension footer outside quote editing, preserve pending quote actions, dismiss the touch keyboard for dictation, and correct launcher button layout.
- Explain GitHub panel CLI startup and timeout failures, and make visual response guidance optional.
- Fix file-download path traversal, isolate Vite optimizer caches between worktrees/servers, and improve websocket heartbeat lease handling.
- Centralize Pi runtime resource ownership and reentrant cleanup while preserving cwd-scoped discovery.
- Harden cross-platform packaged startup/readiness checks, service-worker and browser regressions, and release validation.

No separate global Pi installation is required. Avatar bundles contain their own artwork; no personal avatar artwork is included in the package.
