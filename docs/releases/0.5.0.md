# pi-web 0.5.0

0.5.0 makes pi-web a more capable everyday interface for pi across mobile, desktop, and tablet. This release expands session organization, rich-output viewing, and runtime feedback while improving reliability throughout the app.

## Highlights

- Reorder pinned session tabs and assign session colors directly from the tab menu.
- Inspect session metadata and use new actions for generated artifacts.
- Open Mermaid diagrams in a dedicated full-screen viewer.
- See pending steering and follow-up messages in the conversation before they are sent.
- Use an improved model picker and a tighter folder-selection experience on mobile.
- Reload directly from connection warning badges when recovery is needed.

## Session and runtime improvements

- Preserve the correct runtime state when switching between sessions.
- Make session opening independent from history discovery for more dependable navigation.
- Improve conversation-tree lane packing for complex nested branches.
- Restore new-session state and animation behavior after clearing a session.
- Keep authenticated navigations out of the service worker cache.

## Platform updates

- Update the bundled Pi runtime to 0.82.0.
- Refactor session, realtime, Git, filesystem, artifact, and extension services behind typed boundaries for more reliable future development.

## Positioning

pi-web is a focused interface for pi on every device. It runs locally by default and can be exposed through whichever secure networking or reverse-proxy option best fits the user’s environment.
