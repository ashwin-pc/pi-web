# pi-web 0.5.1

0.5.1 expands pi-web’s everyday agent workspace and launches its new product website. It also makes the local harness boundary explicit: install and authenticate the harness first, then work through it with pi-web.

## Product website

- Add a screenshot-first GitHub Pages website built from real pi-web captures.
- Add high-resolution mobile captures with independent Desktop/Mobile controls and device framing.
- Use the pi welcome animation on the dark homepage hero.
- Add a dark social sharing image and expose the current package version on the homepage, in social metadata, and in the footer.
- Document the honest local setup flow for pi today and the same future boundary for other harnesses.

## Agent workspace

- Add pinned, parked, and bookmarked session lanes with ordering, colors, shortcuts, and touch interactions.
- Add the artifacts explorer, responsive workspace explorer, inline sandboxed HTML previews, and richer Git views.
- Add durable attachment and quoted-reply workflows, including draft recovery across reloads.
- Add extension-contributed panels, settings, session lineage, and the session-orchestration example.
- Improve runtime recovery, session isolation, transcript rendering, notifications, and mobile interaction polish.

## Platform

- Update the pi runtime dependencies to 0.84.1.
- Establish typed, agent-neutral runtime contracts as groundwork for future harness support without claiming that support ships today.
- Restore and stabilize the complete hosted end-to-end test matrix.
