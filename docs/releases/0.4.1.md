# pi-web 0.4.1

0.4.1 improves first-run onboarding for new installs.

## First-run provider setup

- `pi-web` now checks for existing Pi provider configuration before starting.
- If no provider API key, Pi auth file, or custom model config is found, pi-web prompts in the terminal to open the bundled Pi CLI.
- New users can run `/login` in Pi, connect an LLM provider, exit Pi, and pi-web will continue starting.
- Set `PI_WEB_SKIP_PROVIDER_ONBOARDING=1` to skip the prompt.

## Validation
