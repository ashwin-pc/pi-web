# pi-web 0.6.0

0.6.0 expands authentication and Security management, adds core-managed HTTP access for trusted extensions, and improves session organization and the everyday workspace.

## Authentication and Security

- Add passkey and password sign-in with a canonical authentication policy and revocable browser sessions.
- Add credential enrollment, device handoff, API-token management, recent-sign-in checks, and terminal recovery flows.
- Authenticate WebSockets with single-use tickets and harden credential lifecycle, origin validation, and explicitly trusted proxy handling.
- Introduce focused Security management views and confirmation dialogs with native pi-web styling.
- Simplify sign-in to the shared New Session avatar animation, Pi Web title, and available sign-in actions, with reduced-motion support.

Existing authentication methods remain supported; this release does not automatically remove legacy sign-in or change your saved authentication policy. See [authentication and recovery documentation](../passkey-auth.md) before changing deployment settings.

## Extensions and orchestration

- Add core-managed, short-lived scoped HTTP clients for trusted server-side extensions, with explicit route and session targets and runtime-bound revocation.
- Migrate the bundled session orchestrator away from `PI_WEB_TOKEN`, supporting password/passkey-only deployments without a browser credential.
- Add extension panel deep links, system-information contributions, generic extension reports, and recursive session-settlement status.
- Fix extension factory reload through the persistent resource loader.

Extension scopes are not a sandbox for installed code. See [scoped extension HTTP](../extension-http.md) for the route catalogue, lifecycle, and trust model. Copied orchestration extensions must be updated separately; symlinked examples follow their checkout.

## Workspace and sessions

- Add Minimal transcript density, session details and prompt provenance, customizable session buckets, and worker grouping in the session drawer.
- Add mark-unread actions, persistent session notes independent of lanes, and smoother mobile lane switching.
- Improve session title persistence, rerun branching, streaming layout, work-lease cleanup, and session-list performance.
- Add inline audio previews and built-in authenticated artifact downloads; improve mobile artifact layouts and HTML preview resizing.
- Expand the product website's feature coverage and visual tours.

## Validation and diagnostics

- Add bounded request logging, event-loop stall telemetry, and session-list performance regression coverage.
- Isolate test authentication stores and inherited configuration, support separate E2E port ranges, and stabilize shared artifact fixtures and streaming assertions.
- Validate with typecheck, production build, unit tests, and the parallel desktop, tablet, mobile, and authentication browser suites.
