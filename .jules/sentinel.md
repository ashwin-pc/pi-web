## 2024-05-20 - [Fix path traversal in static file server]
**Vulnerability:** The `serveStatic` endpoint had a path traversal vulnerability. It verified files using `file.startsWith(staticDir)`. If `staticDir` was `/app/dist`, a crafted request could resolve to `/app/dist_secret` which evaluates `"/app/dist_secret".startsWith("/app/dist")` to `true`, allowing an attacker to read files in sibling directories with matching prefixes. Additionally, the endpoint had no authentication check since it is outside the `/api/` check.
**Learning:** Checking path boundaries using `.startsWith()` on strings without trailing separators is unsafe. Furthermore, ensuring that local variables do not shadow imported functions is important; fixing this required renaming the local `relative` variable to `reqPath` so that the `relative` function from `node:path` could be used.
**Prevention:** Always use `path.relative` and check if the result starts with `..` or is absolute to verify path bounds correctly, rather than relying on string prefixes.
